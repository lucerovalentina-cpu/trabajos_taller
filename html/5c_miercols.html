HTML

HTML (HyperText Markup Language) es el lenguaje estándar utilizado para estructurar y presentar el contenido de las páginas web. Utiliza etiquetas y elementos para definir encabezados, párrafos, enlaces, imágenes y otros componentes multimedia, formando el "esqueleto" que los navegadores interpretan para mostrar un sitio web.

CSS

(Hojas de Estilo en Cascada), es un lenguaje de diseño utilizado para definir la apariencia visual de documentos estructurados con HTML. Controla elementos como colores, fuentes, diseño y disposición (layout), separando el contenido del formato para facilitar la creación de páginas web atractivas y adaptables a dispositivos.

javacript

JavaScript (JS) es un lenguaje de programación ligero, interpretado y orientado a objetos, fundamental para crear sitios web interactivos y dinámicos. Se ejecuta principalmente en el navegador del usuario (cliente), permitiendo animaciones, validación de formularios y actualizaciones de contenido sin recargar la página
